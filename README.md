# SmartBridge

Platform pembelajaran cerdas berbasis AI.

## Fitur
- **AI Tutor**: Tanya jawab berdasarkan dokumen (RAG).
- **Study Plan**: Buat peta jalan belajar yang dipersonalisasi.
- **Quiz AI**: Uji pengetahuan Anda dengan kuis yang dihasilkan AI.

## Teknologi
- **Frontend**: React + Vite + Tailwind CSS.
- **Backend**: Node.js + Express.
- **AI Model**: Gemini 3.1 Pro via Google GenAI SDK.
